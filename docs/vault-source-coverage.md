# How this public edition maps to the archive

The merged project library is the source archive. It preserves complete documents and historical versions, including unsuccessful experiments and unresolved records. This repository is the public engineering edition derived from that archive.

The private document-by-document matrix records each original location, archived copy, version/date, content hash, related implementation or result, publication eligibility, public destination and omission reason. Administrative records, private operational specifications, raw datasets and material with unresolved reuse rights stay in the archive. They are not represented as secret achieved capabilities.

## What the publication forms mean

| Form | Meaning |
| --- | --- |
| Verbatim | The identified original document bytes are reproduced, as with the short historical study notices. |
| Adapted explanation | A newly written chapter uses the eligible source scope. The complete original specification is not implied to be public. |
| Private archive | The source is accounted for and preserved, with its omission reason in the private matrix. |
| Linked external reference | A separately maintained public resource, such as the reusable skill, is linked at its source rather than copied into this repository. |

[Public source records](source-records.md) list each distinct eligible document version, its date/hash and the public chapters that draw on it. The [machine-readable catalogue](source-records.json) carries the same mapping. Source versions are kept separate from the status of an implementation or experiment.

## Following the evidence

Start with an engineering chapter, follow its source record and read the stated artifact scope. The public software, CAD exchange files and labelled media can be inspected directly. The repository does not reproduce detailed pursuit/interception or operational vehicle-control training instructions. A public reward-methodology explanation is an adaptation, not the full private mathematical specification.

The [reproducibility chapter](reproducibility.md) explains source/public hashes and remote readback. The [experiment-artifact chapter](experiment-artifacts.md) explains the relationship between source, configuration, checkpoints, exports and review records.

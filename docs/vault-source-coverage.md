# Coverage of the project records

The repository contains newly written public explanations and selected artifacts from the project records. It is not a byte-for-byte publication of the Vault. The comparison below distinguishes a public summary from the original source document.

| Project source | Public coverage | Publication form |
| --- | --- | --- |
| Initial autopilot training specification | [Training workflow](training.md), [reward-policy overview](reward-policy-overview.md) | Non-operational explanation; original specification retained privately. |
| Later reward-and-policy design record | [Reward-policy overview](reward-policy-overview.md) | Document structure and evidence distinctions; detailed operational formulas and instructions are not reproduced. |
| Architecture and simulator records | [Simulation](simulation.md), [README architecture](../README.md#how-the-pieces-fit-together) | Public component-level explanation. |
| Perception experiment and dataset records | [Perception](perception.md), [dataset](dataset.md) | Attributed workflow and dataset-version summary; no raw images, embeddings or weights. |
| CAD source and digital checks | [Hardware files](../hardware/), [engineering walkthrough](hardware-engineering.md) | Selected source, exchange files, images and documented digital checks. |
| Pipeline instrumentation | [Software](../software/), [software engineering](software-engineering.md) | Runnable standalone package, examples and tests. |
| Build and simulation media | [Gallery](../media/README.md), [visual walkthrough](visual-walkthrough.md) | Selected, labelled viewing copies with provenance and upstream notices. |
| Artifact preservation and handoff | [Reproducibility](reproducibility.md) | Public explanation of hashes, source identity and remote readback. |

Design specifications describe decisions and intended behavior. Source code documents implementation. Execution logs, evaluations and recordings support narrower claims about what ran or was observed. The public pages preserve those distinctions rather than treating every statement in a planning document as an achieved capability.

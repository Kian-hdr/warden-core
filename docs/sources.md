# Source notes and acknowledgements

These pages summarize retained project records from August and September 2026. Historical experiment records are described as such; this documentation expansion did not rerun training or test a physical vehicle.

## Project records used

| Topic | Retained source record |
| --- | --- |
| Project roles and scope | Annihilation Industries project dossier and team work records. |
| Simulation stack and artifact workflow | Runtime-identity records, simulation documentation and the Skyline archive/recovery record. |
| Training workflow | Saved experiment configurations, training logs, checkpoint inventory and evaluation handoffs. |
| Perception | The August 31 collected linear-probe note, results, training log, metrics and partition records. |
| Hardware | LL-11 source and geometry files, package validation, and the supplied build photographs. |
| Public software | The source and tests distributed under `software/`. |
| Media | Original render metadata and labels, plus the supplied photo collection. |

The full private archive is retained separately. This repository publishes a scoped explanation and selected artifacts, not a raw export of internal notes, machine credentials or third-party datasets.

## Tools and upstream work

- [NVIDIA Brev](https://docs.nvidia.com/brev/getting-started/overview): remote GPU development infrastructure.
- [NVIDIA Isaac Sim](https://docs.isaacsim.omniverse.nvidia.com/4.5.0/index.html) and [Isaac Lab](https://isaac-sim.github.io/IsaacLab/): simulation and robot-learning tools.
- ImageNet-pretrained ResNet18 features: the starting representation used in Vincent’s offline baseline, not a visual backbone trained from scratch by the team.
- CadQuery: the parametric CAD tool used for the supplied landing-leg source.

Product names identify tools used. They do not imply endorsement, sponsorship or a partnership. Upstream software, assets and datasets retain their own terms; no blanket license over them is granted here.

Simulation media attribution and the retained upstream licence notices are in [media credits](../third_party/README.md).

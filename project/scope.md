# Repository scope

This is a curated public collection from Annihilation Industries / Warden Core. It has a fresh Git history. The original development repositories and archive remain separate.

## Included

- Standalone pipeline observability and offline assessment tools.
- Selected tests and usage examples.
- Custom LL-11 leg geometry, editable source and a leg-only preview.
- Selected project photographs, a labelled simulation preview and two attributed development videos.
- Project, simulation, training, perception and dataset documentation grounded in retained records.

## Kept outside this collection

The full development archive, training datasets and weights, internal documentation, machine configuration, credentials, operational endpoints and original Git history are not included. Neither are commercial reference geometry, vendor printer presets or material whose redistribution rights are unclear. Warden Corps sensing work is a separate project.
